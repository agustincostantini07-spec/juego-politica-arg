ARGENTUM 2D — AMPLIACIÓN PRIORITARIA: SISTEMA POLÍTICO COMPLETO + MEDIDAS DE GOBIERNO

ESTA ES UNA AMPLIACIÓN PRIORITARIA DEL PROMPT ANTERIOR.

NO QUIERO QUE LA POLÍTICA DE ARGENTUM 2D SE LIMITE A:

LOBBY
→ CAMPAÑA
→ ELECCIÓN
→ PRESIDENTE
→ FIN.

LA ELECCIÓN ES SOLAMENTE EL COMIENZO.

QUIERO QUE GOBERNAR, SER OPOSICIÓN, NEGOCIAR, LEGISLAR Y TOMAR MEDIDAS SEA EL NÚCLEO PRINCIPAL DE ARGENTUM 2D.

EMPEZÁ A IMPLEMENTAR ESTA PARTE YA, EN PARALELO CON LA BASE MULTIPLAYER/ONLINE SEGÚN EL ORDEN TÉCNICAMENTE NECESARIO.

TODO EL ESTADO POLÍTICO IMPORTANTE DEBE SER COMPARTIDO Y AUTORITATIVO EN LA PARTIDA ONLINE.

4. PROMESAS ELECTORALES
==================================================

Durante campaña:

los candidatos pueden realizar PROMESAS.

Ejemplo:

BAJAR IMPUESTOS.

AUMENTAR PRESUPUESTO DE SALUD.

AUMENTAR PRESUPUESTO POLICIAL.

REDUCIR DÉFICIT.

AUMENTAR SALARIOS PÚBLICOS.

REFORMAR JUSTICIA.

CAMBIAR REGULACIÓN DE ARMAS.

Las promesas quedan registradas.

Después de asumir:

el juego compara:

PROMETIDO
vs
REALIZADO.

Cumplir promesas puede afectar confianza.

Incumplirlas también.

Pero considerar contexto:

una promesa puede fracasar porque Congreso rechazó el proyecto.

NO tratar automáticamente eso igual que decidir abandonarla.

==================================================

10. CADENA REAL DE UNA MEDIDA
==================================================

EJEMPLO:

→ define tasa actual y propuesta.

→ Congreso recibe proyecto.

→ partidos evalúan.

→ comienza negociación.

→ se vota.

BudgetSystem recibe nueva recaudación.

EconomicSystem empieza a reaccionar.

TODO ESO DEBE SER UNA CADENA REAL.
